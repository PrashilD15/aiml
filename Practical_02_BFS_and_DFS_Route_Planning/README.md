# Practical 2: Route Planning using BFS and DFS

## Required Libraries
- Uses only Python built-in standard library (`collections`, `time`). **No `pip install` required.**

## Ubuntu Linux Execution Commands

```bash
cd Practical_02_BFS_and_DFS_Route_Planning
python3 practical_02.py
```

### If `python3` is not installed on Ubuntu
```bash
sudo apt update && sudo apt install -y python3
```
