# Practical 3: Rule-Based Expert System (Forward & Backward Chaining)

## Required Libraries
- Uses only Python built-in standard library. **No `pip install` required.**

## Ubuntu Linux Execution Commands

```bash
cd Practical_03_Rule_Based_Expert_System
python3 practical_03.py
```

### If `python3` is not installed on Ubuntu
```bash
sudo apt update && sudo apt install -y python3
```
