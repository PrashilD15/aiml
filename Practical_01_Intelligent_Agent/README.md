# Practical 1: Intelligent Agents (Chatbot, Recommendation Assistant & Smart Home Controller)

## Required Libraries
- Uses only Python built-in standard library (`datetime`). **No `pip install` required.**

## Ubuntu Linux Execution Commands

```bash
cd Practical_01_Intelligent_Agent
python3 practical_01.py
```

### If `python3` is not installed on Ubuntu
```bash
sudo apt update && sudo apt install -y python3
```
